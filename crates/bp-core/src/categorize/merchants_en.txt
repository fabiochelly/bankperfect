# English-language merchant and keyword dictionary for BankPerfect.
#
# Used instead of commercants.txt when the interface is in English. Covers
# major chains and services in the United Kingdom, the United States,
# Canada, Ireland and Australia, international brands, and generic English
# words found on bank statements.
#
# Same syntax as commercants.txt:
# one section per generic category: [slug] (see taxonomy.rs);
# one entry per line: lowercase words without accents, matched as whole,
# consecutive words in the payee, then in the memo. A trailing "*" accepts
# any word ending ("sainsbury*"). Punctuation splits words: "M&S" is "m s",
# "MCDONALD'S" is "mcdonald s", "7-ELEVEN" is "7 eleven".
#
# Options after ";", separated by spaces:
#   -          expenses only             +       income only
#   <30        amount <= 30              >100    amount >= 100
#   20..80     amount between 20 and 80
#   ~          weak hint (ambiguous name, common word)
#   @cb @prlv @vir @dab @chq   transaction type (card, direct debit,
#              transfer, ATM withdrawal, cheque)
#
# The longest entry wins; at equal length the payee comes before the memo.
# A more specific memo refines a generic payee ("hmrc" then "self
# assessment" -> income tax). Income sections ([revenus.*]) only match
# credits.
